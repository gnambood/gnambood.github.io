01 · ML application / deployed architecture

Auto Market Assistant

What should a comparable used car cost, and what do its owners actually say? I built historical asking-price estimation with CatBoost and cited review retrieval with MiniLM and FAISS, supported by curated Parquet data, FastAPI, Docker and an AWS ECS deployment.

Optional Qwen 2.5 generation was evaluated separately. The deployed service uses retrieval-only answers and its cloud compute is currently paused. The portfolio demo explores saved model outputs without contacting AWS.

02 · Graduate research / computer vision

Driver Impairment Classification

Can tiny changes in facial behaviour help distinguish impairment levels? At Western University's AiX Lab, I investigated synchronized RGB and infrared video, explored TimeSformer, Video Swin and ViViT, and retained separately evaluated TimeSformer and personalized VideoMAE research pipelines.

03 · Security analytics / machine learning

Insider Threat Detection

What happens when suspicious activity is scattered across many logs? I developed behaviour-based features from simulated enterprise records and compared Logistic Regression, RBF SVM and Random Forest to investigate insider-risk classification.
