An end-to-end ML application for historical vehicle asking prices and evidence-backed owner reviews. CatBoost handles numerical estimates; MiniLM and FAISS find relevant owner experiences. Data, inference, and the browser demo are separate, testable parts.

The system can abstain.

Questions first pass a capability guard that blocks exact-vehicle condition/history, current transactional data and authoritative-specification requests. In-scope questions then pass a calibrated evidence gate using max similarity, mean top-3 similarity and the number of supporting reviews. Generated source IDs are validated against the reviews that were actually retrieved.

Metrics evaluate separate tasks, not the accuracy of this one saved vehicle example. See the model card.
